# Task API

ამოცანების მართვის მცირე REST API. მონაცემებს ინახავს მეხსიერებაში, ხოლო თუ `REDIS_URL` მითითებულია, Redis-ში.

## გაშვება

```bash
npm ci
npm test
npm start
```

სერვისი უსმენს პორტს `3000`, ან `PORT` ცვლადში მითითებულს.

## Endpoint-ები

| მეთოდი | მისამართი | აღწერა |
| --- | --- | --- |
| GET | `/health` | 200, თუ საცავი ხელმისაწვდომია, სხვა შემთხვევაში 503 |
| GET | `/version` | აპლიკაციის ვერსია |
| GET | `/tasks` | ამოცანების სია, არჩევითი ფილტრი `?priority=` |
| POST | `/tasks` | ამოცანის შექმნა |
| GET | `/tasks/:id` | ერთი ამოცანა |
| POST | `/tasks/:id/complete` | ამოცანის დასრულება |
| DELETE | `/tasks/:id` | ამოცანის წაშლა |
| GET | `/stats` | სტატისტიკა |

## ბიზნეს წესები

1. `title` სავალდებულოა. თავსა და ბოლოში გამოტოვებები იჭრება და ინახება გასუფთავებული მნიშვნელობა.
2. გასუფთავების შემდეგ `title` უნდა იყოს 1-დან 100 სიმბოლომდე. სხვა შემთხვევაში პასუხია 400.
3. `priority` არის `low`, `medium` ან `high`. ნაგულისხმევია `medium`. სხვა მნიშვნელობაზე პასუხია 400.
4. `GET /tasks` პირველ რიგში აბრუნებს უახლეს ამოცანებს.
5. უკვე დასრულებული ამოცანის ხელახლა დასრულება აბრუნებს 409-ს და `completedAt` არ იცვლება.
6. არარსებულ ამოცანაზე პასუხია 404.
7. `doneRate` არის დასრულებული ამოცანების პროცენტი, მთელ რიცხვამდე დამრგვალებული. ამოცანების არარსებობისას ის 0-ია.
8. `dueDate` არჩევითია, ფორმატით `YYYY-MM-DD`. არასწორ ფორმატზე ან წარსულ თარიღზე პასუხია 400.
